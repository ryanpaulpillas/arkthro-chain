# Security policy

ARKTHRO is on its public testnet. Test ARKTH has no cash value.

## Reporting a vulnerability

Email **paulgallardopillas@gmail.com** (temporary address while ARKTHRO is being built) with:

- what you found and where (node, RPC, explorer, wallet, arkthro.com services),
- steps to reproduce,
- the impact you expect.

Please do not open a public GitHub issue for security problems, do not test against other people's accounts or funds, and do not run denial-of-service tests against the public servers.

We aim to reply within 7 days.
